# 第16回｜1つの発信を複数媒体へ展開する量産・自動化

[全体の目次](../../README.md) · [カテゴリの目次](../README.md)

長尺動画、LIVE、記事など、一つの「親コンテンツ」をAIで再編集し、ショート動画、SNS投稿、LINE、記事などへ展開します。毎回ゼロから作らず、内容の一貫性と人間による最終確認を残した仕組みを作ります。
