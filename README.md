# AI講座 プロンプト・講義資料集

全16回のAI講座で使う40本のプロンプトを、用途別のMarkdownファイルで公開しています。基礎から市場調査、企画づくり、画像・資料制作、SNS発信、運用まで、講座の順に取り組むことも、必要なものだけ選ぶこともできます。

全16回の講義資料PDFも公開しています。[講義資料の一覧はこちら](materials/README.md)。

## はじめて使う方へ

1. 下の目次から講座を選び、使いたいプロンプトを開きます。
2. 「コピーして使うプロンプト」の枠内をコピーします。
3. 入力例・差し込み箇所をご自身の内容へ書き換え、必要な資料を添えます。
4. 利用するAIへ貼り付け、返ってきた質問へ答えながら進めます。

閲覧・コピーのためのGitHubアカウント登録は不要です。各AIサービスの利用には、そのサービスのアカウントや対応機能が必要な場合があります。

[詳しい使い方・確認事項](HOW_TO_USE.md) · [プロンプトを追加・改善する](CONTRIBUTING.md) · [新規プロンプト用テンプレート](templates/prompt-template.md)

## 講座の成果物をつなぐ

市場調査（第3〜4回）と人生ストーリー（第5回）からコンセプト（第6回）を考え、企画書（第7回）へまとめます。購入・予約・申込先（第8回）を、チラシ・資料・LP（第9〜11回）やSNS・動画・LINE（第12〜15回）で案内し、第16回で一つの発信を複数の媒体へ展開します。

完成した企画書や調査結果は手元に保存し、次の回で必要な資料として渡してください。このリポジトリに個人の回答や顧客情報を投稿する必要はありません。

## 収録方針

講座の配布用プロンプト40本の本文を保持し、個別ファイルに整理しています。使い方と架空の入力例を追加しました。講師用台本や個人の回答は収録していません。AIの出力例や各サービスでの動作保証を示すものではありません。
