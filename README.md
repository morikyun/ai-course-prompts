# AI講座｜仕事・企画・発信に役立つプロンプト＆講義資料集

AIを使って、調べる・考える・つくる・届ける。

この講座では、AIへの基本的な頼み方から、市場調査、自己分析、企画づくり、画像・資料制作、SNS発信、運用までを全16回で学びます。自分の経験やアイデアを、具体的な企画や発信へつなげるための実践型教材です。

このリポジトリ（資料置き場）では、**40本のプロンプトと全16回の講義資料PDF**を公開しています。プロンプトとは、AIに依頼するときに入力する指示文のことです。講座の順に学ぶことも、今の課題に合うものだけ選んで使うこともできます。

## こんな方におすすめです

- **AIを使い始めた方**：何を頼めばよいか、どう指示すればよいかを実例から学びたい
- **個人事業主・講師・発信者の方**：自分の経験や強みを整理し、商品・サービスの企画や発信に生かしたい
- **小規模事業の企画・広報担当者の方**：調査、企画書、告知画像、資料、SNS投稿などの作業にAIを取り入れたい
- **AIを試したものの活用が続かなかった方**：単発の質問から一歩進み、実際の仕事の流れで使いたい

AIの専門知識やプログラミング経験を前提とせず、対話しながら取り組む内容が中心です。AIモデルの開発やプログラミングを専門的に学ぶ講座ではありません。

## この講座で取り組めること

講座を通して、次のような成果物づくりに取り組みます。

| 学ぶこと | 作成・整理するもの |
| --- | --- |
| AIの使い分けと頼み方 | 自分の目的に合ったプロンプト |
| 市場調査と情報整理 | 市場・競合の調査結果、集めた情報の整理 |
| 自己分析と企画づくり | 自分の強み・発信軸、コンセプト、企画書 |
| 販売の仕組みづくり | 購入・予約・申込みまでの流れ |
| 画像・資料・Webページ制作 | 告知画像、スライド、LP（商品・サービスの案内ページ） |
| 発信と運用 | SNSの方針、動画の企画・台本、LINEの活用方針、複数媒体への展開案 |

AIが出した内容をそのまま完成品にするのではなく、自分の目的や事実に照らして確認・修正しながら仕上げていきます。

## はじめて使う方へ

### 用意するもの

- 講座で使うAIサービスを利用できる環境
- 取り組みたいテーマや課題（まだ曖昧な状態でも構いません）
- 必要に応じて、自分の商品・サービスの情報や参考資料

主にChatGPT・Gemini・Claudeなどを扱います。回によって、画像生成や資料の読み込み、外部サービスなどを利用します。

**この資料の閲覧・コピーにGitHubアカウントは不要です。** 各サービスの利用には、アカウント登録や対応プランが必要な場合があります。教材の利用条件とは別に、サービス側の料金が発生する場合があります。

### 基本の使い方

1. 下の目次から、取り組みたい回を選びます。
2. 講義資料PDFで、その回の考え方や進め方を確認します。
3. プロンプトのページを開き、「コピーして使うプロンプト」の枠内をコピーします。
4. 入力例・差し込み箇所を自分の内容に書き換え、必要な資料を添えてAIに送ります。
5. AIからの質問に答え、出力を確認・修正しながら進めます。

入力例は架空のものです。自分の状況に置き換えて使ってください。

[詳しい使い方・確認事項](HOW_TO_USE.md)

## どこから始めるか迷ったら

- **AIの基本から学びたい** → 第1〜2回
- **情報収集や整理に使いたい** → 第3〜4回
- **自分の強みやサービスの企画を整理したい** → 第5〜8回
- **画像・資料・Webページをつくりたい** → 第9〜11回
- **SNSや動画で発信し、運用につなげたい** → 第12〜16回

一つの企画を育てながら学びたい方は、第1回から順に進めるのがおすすめです。途中の回から始める場合は、そのプロンプトで必要な企画情報や参考資料を用意してください。

## 各回の成果物をつなげて使う

各回で作ったものを次の回に渡すことで、一つの企画を具体化していけます。

1. **調べる・自分を知る（第3〜5回）**  
   市場・競合の情報と、自分の経験や強みを整理します。
2. **企画にする（第6〜8回）**  
   コンセプトと企画書をまとめ、購入・予約・申込みまでの流れを考えます。
3. **伝えるものをつくる（第9〜11回）**  
   企画をもとに、チラシ・画像・資料・LPを制作します。
4. **発信する・運用する（第12〜16回）**  
   SNS・動画・LINEで届け、一つの発信を複数の媒体へ展開します。

調査結果や企画書は手元に保存し、次の回で必要な資料としてAIに渡してください。別の会話や別のAIサービスには、それまでの内容が自動で引き継がれるとは限りません。

## 利用時の確認事項

- **AIの回答は確認して使ってください。** 調査結果の出典・日付・数値や、公開する文章の内容は、元の情報に当たって確認しましょう。
- **入力する情報を選んでください。** 個人情報・顧客情報・社外秘の資料などは、所属先のルールや利用サービスのデータの扱いを確認してから入力してください。
- **制作物は公開前に見直してください。** 文章・画像・資料に含まれる誤りや、第三者の著作物・商標などの扱いを確認しましょう。
- **画面や機能が教材と異なる場合があります。** AIサービスの更新や利用プランによって、同じ手順で進められないことがあります。

このリポジトリに個人の回答や顧客情報を投稿する必要はありません。
